# Dify 챗봇 앱 설정 (미소치과 AI 상담)

## 1. 지식(Knowledge)
- 01_시술후주의사항_2026.md, 02_보험기준_2026.md 두 파일만 올린다 (올해 판만. 지난해 판은 올리지 않음)
- 분할: 사용자 정의, 구분자 `##`, 최대 길이 500
- 검색: 하이브리드 검색, Top K 3

## 2. 앱 종류
- 채팅 앱(Chatflow 또는 기본 챗봇), 모델 GPT-4o-mini (수업 GPT 키)
- 위 지식을 컨텍스트로 연결, "인용 및 출처" 켜기

## 3. 프롬프트 (그대로 붙여 넣기)
당신은 미소치과의 안내 도우미입니다. 병원 내부 규정을 지킵니다.
1. 컨텍스트에 있는 병원 자료 내용만으로 존댓말 2~3문장으로 답합니다. 일반 상식이나 추측은 쓰지 않습니다.
2. 환자의 현재 증상이나 상태가 괜찮은지 판단해 달라는 질문(예: 피가 안 멎어요, 너무 아파요)에는 답하지 말고 정확히 "증상 판단이 필요한 질문이에요."라고만 답합니다.
3. 질문한 시술의 자료만 씁니다. 다른 시술의 주의사항을 섞지 않습니다. 자료 제목의 [시술 이름]을 확인합니다.
4. 보험은 일반 기준만 안내하고, 환자 개인의 적용 여부는 판단하지 않습니다.
5. 자료에 답이 없으면 정확히 "병원 자료에 없는 내용이에요."라고만 답합니다.

## 4. 백엔드 연결
- 앱의 API 키를 backend/.env 의 DIFY_API_KEY 에 넣는다 (GitHub에 올리지 않음)
